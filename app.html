📖 使用说明（点击展开）

① 题库参数

  • 考试名称：必填，目标考试/科目。
  • 总题数 ÷ 每批题数 = 批次数，批次数即要生成的 TXT 文件数。
  • 例：总题数 900、每批 150 → 6 批，生成 6 个文件。
  • 时政下限：涉及时政/热点的题，事件日期不得早于此值。

② 参考文档（出题知识库）

  • 上传 .txt / .md 文件作为出题依据，模型优先依据其内容出题。
  • 支持多文件，单文件过大自动截断；内容只在本页内存使用，不上传第三方。

③ 大模型 API

  • Base URL 填服务商接口（以 /v1 结尾），模型名填该服务商存在的模型。
  • API Key 必须纯英文/数字，不能含中文、换行、全角。
  • 本地 Ollama：Base URL=http://localhost:11434/v1，模型名用 ollama list 里的，API Key 随便填非空。

④ 模块规划

  • 每批 1 行，格式：模块名 | 知识点要点 | 题型。
  • 行数必须等于批次数，多一少一都会报错。
  • 可点「自动规划」让模型填写，也可手动写。

⚠ 提示

  • 本页在独立浏览器标签页运行。生成期间请勿关闭该标签页，否则生成会中断。
  • 已完成的批次不会丢失——每批完成即下载保存。
  • 切换到其他标签页浏览不影响生成（页面仍在运行）。
