# 陆小马刷题题库生成器（浏览器插件版）

把「题库开发通用技能」做成 Chrome/Edge 浏览器插件：输入参数（考试名称、题量、每批题数、难度、时政下限、大模型 API），自动规划知识模块、分批生成高频易错题，并把每批 TXT 保存到本地下载目录。

> **界面形态**：点击工具栏图标会在**独立浏览器标签页**打开全功能页面，而非小弹窗。页面可随时切换标签页浏览其他内容，不影响后台生成。

## 功能

- **参数化输入**：考试名称、总题数、每批题数、科目前缀、难度分级、时政下限、是否含解析
- **大模型 API 可配置**：任意 OpenAI 兼容接口（DeepSeek / Kimi / 智谱 / OpenAI / Ollama 本地等）
- **自动规划**：一键让模型按考试大纲划分知识模块并分配到各批次
- **手动规划**：也支持手写每批模块（`模块名 | 知识点要点 | 题型`）
- **分批生成**：逐批调用 API，全程复用技能的格式规范、出题规则、答案分布约束
- **参考文档（知识库）**：可上传 `.txt / .md` 文件作为出题依据，模型优先依据其内容出题（覆盖大纲、教材、资料）；支持多文件，过大自动截断
- **本地保存**：每批生成后自动通过浏览器下载 TXT（UTF-8 带 BOM，Excel/记事本兼容）
- **配置记忆**：所有参数自动保存在浏览器本地，下次打开自动恢复
- **VIP 卡密认证**：对接鸽子云网络验证（APPID 925），激活卡密解锁无限题量、并行生成等高级功能；授权状态本地缓存，断网也能用已激活权益

## 安装（未上架，需开发者模式加载）

1. 打开 Chrome / Edge，地址栏输入 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本文件夹 `qbank-browser-extension`
4. 工具栏点扩展图标 → 浏览器会**新开一个标签页**打开主界面（`app.html`）
5. 也可直接在地址栏访问 `chrome-extension://<扩展ID>/app.html` 打开主界面

> 修改代码后记得在扩展管理页点该扩展的「重新加载」按钮使其生效。

## 使用步骤（四步）

1. **填题库参数**（见下「参数输入说明」）
2. **上传参考文档（可选）**：在「1.5 参考文档（出题知识库）」卡片选择 `.txt / .md` 文件，作为出题依据
3. **填 API 配置**，点「测试连接」验证
4. **规划知识模块**：点「自动规划」或手动填写（见下「模块规划」）
5. **点「开始生成」**：逐批出题，每批完成后自动下载到本地下载目录

> 上传的参考文档内容仅在当前页面内存中使用，不会上传给插件开发者或第三方；刷新页面后需重新选择。

> **VIP 卡密**：未激活时总题数上限 30 题；激活鸽子云卡密后解锁无限题量等 VIP 功能。详见下方「VIP 卡密认证」。

## VIP 卡密认证（鸽子云）

插件集成**鸽子云网络验证系统**（geziyun.cn，应用 APPID = 925），用于 VIP 解锁。

### 免费版 vs VIP 版

| 能力 | 免费版 | VIP 版（激活卡密后） |
|---|---|---|
| 总题数上限 | 30 题 | 无限 |
| 多考试并行 / 批量生成 | ✗ | ✓ |
| 其他高级策略 | ✗ | ✓ |

### 获取卡密

打开插件页面后，**右侧悬浮卡片**会显示「陆小马学习资料站」公众号二维码：

1. 微信扫码关注公众号「陆小马学习资料站」
2. 回复关键词 **「卡密」**
3. 按公众号指引获取卡密

> 若二维码未显示，请检查插件目录下是否存在 `qrcode.jpg` 图片文件。

### 激活步骤

1. 在页面顶部「VIP 卡密认证」卡片输入卡密，点「激活 VIP」。
2. 插件调用鸽子云 `kmlogon` 单码登录接口校验卡密有效性（自动附加本机机器码）。
3. 校验成功后，卡密与到期时间会**缓存到本地**，顶栏徽章变为「VIP 已激活」，题库参数上限解除。
4. 已激活状态下**断网也能继续用**（本地校验到期时间，到期前无需再次联网）。

### 解绑本机

点「解绑本机」调用鸽子云 `kmunmachine` 接口，清除本机卡密的设备/IP 绑定，方便把卡密换到其他机器使用。

> 公告与版本提示来自鸽子云 `notice` / `ini` 接口，会在 VIP 卡片顶部展示。

## 参数输入说明

### 一、题库参数

| 参数 | 说明 | 示例/默认 |
|---|---|---|
| **考试名称** | 必填。你要出题的目标考试/科目。 | 注册会计师 |
| **科目前缀** | 四位序号前缀，用于区分不同考试；同一考试各批相同。 | `0001` |
| **总题数** | 整个题库的题目总量。**必须是「每批题数」的整数倍**。 | 900 |
| **每批题数** | 每批生成的题目数，也是每个 TXT 文件的题量。 | 150 |
| **难度** | 不分级 / 初级 / 中级。仅当考试明确分级别时选择。 | 不分级 |
| **时政下限** | 涉及时政、热点、政策的题目，事件日期不得早于此值。 | 2025-06 |
| **包含解析** | 勾选后每道题附 `解析：...` 行。 | 勾选 |

> **批次数 = 总题数 ÷ 每批题数**。例如总题数 900、每批 150 → **6 批**。
> 系统会生成 6 个 TXT 文件，每批一个。

### 二、大模型 API

| 参数 | 说明 | 示例/默认 |
|---|---|---|
| **API Base URL** | 你所用服务商的 OpenAI 兼容接口地址（以 `/v1` 结尾）。 | `https://api.deepseek.com/v1` |
| **模型名** | 服务商内实际存在的模型 ID。**必须与所选服务商匹配**。 | `deepseek-chat` |
| **API Key** | 你的密钥，必须是**纯英文/数字**，不能含中文、换行、全角字符。 | `sk-...` |
| **Temperature** | 生成随机性，0~1。出题建议 0.6~0.8。 | 0.7 |
| **Max Tokens** | 单次输出上限。题量大或每批题数多时应调大（本地小模型尤需）。 | 8192 |

> **本地 Ollama** 用法：
> - Base URL：`http://localhost:11434/v1`
> - 模型名：用 `ollama list` 里实际存在的，如 `qwen2.5:3b`
> - API Key：本地不校验，随便填个非空值（如 `ollama`）
> - 需设置环境变量 `OLLAMA_ORIGINS="*"` 后重启 Ollama，否则扩展跨域请求会被 403 拒绝（详见「常见问题」）

### 三、模块规划

批次数 = 总题数 ÷ 每批题数。你需要为**每一批**规划一个知识模块。

**方式 A：自动规划**
- 点「自动规划」，让模型按考试大纲自动划分各批模块并填入文本框。
- 若失败，多因本地小模型输出被截断或 JSON 不规范，可调大 Max Tokens 重试，或改用手动规划。

**方式 B：手动规划**
- 在文本框里，**每批写一行**，格式：`模块名 | 知识点要点 | 题型`
- **行数必须恰好等于批次数**（多一行或少一行都会报错）。
- 示例（总题数 900、每批 150 → 6 批）：
  ```
  民法总论 | 民事法律关系、自然人、法人 | 单选、判断、简答
  合同法 | 合同成立、效力、违约责任 | 单选、多选、案例分析
  物权法 | 所有权、用益物权、担保物权 | 单选、判断、名词解释
  侵权责任法 | 归责原则、特殊侵权、责任承担 | 单选、多选、案例分析
  婚姻家庭法 | 结婚、离婚、继承 | 单选、判断、简答
  经济法 | 市场主体、竞争法、消费者权益 | 单选、多选、论述
  ```
- 请确认所有大纲知识模块都被覆盖，系统不会自动检查遗漏。

## 兼容的 API

任何 OpenAI 兼容的 `/chat/completions` 接口均可：

| 服务 | Base URL | 示例模型 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| Kimi (Moonshot) | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| 本地 Ollama | `http://localhost:11434/v1` | `qwen2.5:3b` / `qwen2.5:14b` |

> 本地 Ollama 需设置 `OLLAMA_ORIGINS="*"` 并重启，否则扩展跨域请求会被 403 拒绝。

## 重要：关于「关闭页面导致生成停止」

**请务必注意：生成过程中，不要关闭主界面所在的浏览器标签页。**

- 本插件采用**独立标签页**（`app.html`）运行。**在浏览器标签页里打开，切换到其他标签页浏览、最小化浏览器等操作都不会中断生成**——页面仍在后台运行。
- 但若**关闭该标签页**（或浏览器重启、崩溃），生成进程会中断。
- 原因：生成逻辑运行在页面内，页面被销毁即终止。
- **已生成的批次不会丢失**：每完成一批都会立刻下载到本地下载目录，因此已完成的部分已经保存。
- 中断后**未生成的批次**不会自动续跑，需重新点「开始生成」（会从头生成，包括已完成的批次——建议用「手动规划」删掉已完成的行，或用不同科目前缀避免覆盖）。

**如何避免中断：**
1. 生成期间**不要关闭**主界面所在标签页，不要关闭浏览器/重启电脑。
2. 可以放心切换到其他标签页浏览网页，不影响生成。
3. 想中途休息，可等当前批完成、文件下载后再关闭；下次重新打开继续剩余批次（手动规划只保留未生成的批次）。
4. 如果题量大，建议调小每批题数，减少单次生成耗时。

> 说明：相比早期「弹窗」版本，独立页面已解决「点击页面外导致弹窗失焦关闭」的误中断问题，大幅提升稳定性。

## 常见问题

- **总题数提示不整除**：总题数必须是每批题数的整数倍，如 900/150。
- **手动规划报「行数与批次数不符」**：手动规划行数必须 = 总题数 ÷ 每批题数。先算好批次数，每批 1 行。
- **自动规划失败**：多因本地小模型输出被截断或 JSON 不规范。调大 Max Tokens 重试，或改用手动规划。
- **HTTP 403（本地 Ollama）**：需先 `setx OLLAMA_ORIGINS "*"`，退出并重启 Ollama，再测试连接。
- **"返回内容为空"**：模型名或 Base URL 配错；部分模型不支持 `max_tokens` 参数。
- **生成题数偏少**：模型输出受 `max_tokens` 限制，可增大 Max Tokens 或减小每批题数。
- **下载位置**：文件保存到浏览器「下载」目录；文件名格式 `科目前缀-考试名-批次-模块.txt`。

├── manifest.json       # 扩展清单（Manifest V3）
├── background.js       # Service Worker：点击图标时打开主界面标签页
